# Contributing

## Purpose

This repository uses a visible, reusable starter structure so both humans and agents can work from the same documented expectations.

## Source of truth

- Canonical superprompt: `/home/runner/work/bondova-MOR/bondova-MOR/docs/superprompt.md`
- Agent roles and limits: `/home/runner/work/bondova-MOR/bondova-MOR/AGENTS.md`

If agent behavior conflicts with these files, these repository documents take precedence.

## Approval policy

- Do not make destructive changes without explicit confirmation.
- Do not perform broad repository restructuring without explicit confirmation.
- Do not rely on hidden prompt-only behavior when the same rule is not visible in the repository.

## Contributor expectations

- Keep changes scoped to the task.
- Prefer visible documentation for shared rules and collaboration norms.
- Document material changes to repository structure or working agreements.
- Preserve existing starter files unless there is explicit approval to change them.

## Review expectations

- Review agent-produced changes before accepting them.
- Confirm that changes match the visible repository rules.
- Confirm that approval boundaries were respected.
- Confirm that project-specific details remain separate from reusable starter guidance.
